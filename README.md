# WiDS Datathon++ 2025 University Challenge
## Age Prediction from fMRI Connectivity Data —Using Autoencoder and Regularized Regression


### Group members: 
#### Liwen Yin, Jin Wen Lin, Zilu sun, Xiaohan Shi

The objective of this project is to predict each individual’s age based on the fMRI data provided by Healthy Brain Network (HBN) and a metadata that includes demographic features. The fMRI data focused on each participant’s brain activity during the resting-state. To have a better understanding of the large number of the features, Principal Component Analysis (PCA) and autoencoder were used for dimension reduction. We applied regularization regression models and further explored the machine learning approach—XGBoost to enable performance comparison. To enhance model performance, we utilized neural networks with techniques such as early stopping, grid search, the Adam optimizer, and dropout regularization. The model performances were evaluated by comparing the metrics of Rooted Mean Squared Error (RMSE) and Coefficient of Determination (R2).
